A few things you can do:

- `display.show(Image.HAPPY)` — built-in faces (HAPPY, SAD, ARROW_E, YES, NO, …)
- `music.play(['C4:4','E4:4'])` — short tunes
- `accelerometer.was_gesture('shake')` — single-shot gesture
- `radio.on(); radio.send('hi'); msg = radio.receive()` — talk to other ducks
